# 결 성격유형 검사

60문항 · 약 10분짜리 성격유형 검사 웹페이지입니다. 서버 없이 `index.html`만 열면 동작하고, 외부 라이브러리도 쓰지 않습니다.

## 특징
- **5개 축 × 하위 측면 2개 × 6문항 = 60문항.** 질문과 순서는 항상 같습니다(`js/questions.js`).
- 7점 척도로 답하고, 축마다 0~100% 연속 점수를 냅니다. 45~55%는 "경계"로 표시하고 인접 유형을 안내합니다.
- 4글자 유형(16가지) + 정서 접미사 `-C/-E` = 32가지 프로필.
- 결과: 유형 소개, 5축 그래프, 하위 측면 10개 해석, 강점·약점, 추천 직업, 잘 맞는/보완/부딪히는 유형, 연애·친구·일·스트레스·성장 조언.
- 응답 신뢰도 검사(모순 응답, 연속 같은 번호, 중립 과다, 너무 빠른 응답).
- 궁합 계산기, 16유형 전체 보기, 결과 링크 공유(`#r=` 뒤에 60자리 숫자), 인쇄/PDF 저장, 진행 상황 자동 저장.

## 유형 체계
| 축 | 측정 대상 | A | B | 하위 측면 |
|---|---|---|---|---|
| 에너지 | 외향성 | O 외향 | R 내향 | 사교성 / 주도성 |
| 인식 | 개방성 | V 탐구 | G 현실 | 상상·사고 / 새로움 개방 |
| 판단 | 친화성 | H 공감 | L 원칙 | 공감 / 조화·배려 |
| 생활 | 성실성 | S 계획 | F 유연 | 질서·계획 / 성실·완수 |
| 정서 | 신경성 | C 안정 | E 민감 | 걱정·불안 / 감정 기복 |

기질 그룹(인식×판단): VL 전략가군, VH 이상가군, GL 실무가군, GH 조화가군.

## 채점 (`js/scoring.js`)
1. 문항 점수 = 응답(-3~+3) × 방향(A 방향 +1, B 방향 -1)
2. 축 합계(-36~+36) → A 방향 % = (합+36)/72×100
3. 합이 0보다 크면 A, 작으면 B. **정확히 50%면 B**로 정합니다(축은 하위 측면 2개로 이뤄져, 합이 0이면 두 측면의 치우침 크기가 같아 어느 쪽도 우세하지 않기 때문에 항상 같은 값으로 고정).
4. 뚜렷함: |%-50| 기준 0~5 경계 / 5~15 약간 / 15~30 뚜렷 / 30 이상 매우 뚜렷
5. 응답 신뢰도 = 100 − 감점
   - 모순 응답(같은 하위 측면의 짝 문항 둘 다 강하게 동의 또는 강하게 부정) 비율 15% 초과분 × 100, 최대 40점
   - 같은 번호 12문항 이상 연속: 40점
   - 0(보통) 응답 40% 초과: 30점
   - 문항당 평균 1.5초 미만: 30점 (결과 링크로 열 때는 시간 정보가 없어 검사하지 않음)
   - 75점 미만이면 결과 상단에 재검사 권장을 표시

### 궁합 지수
`3×[인식 같음] + 2×[판단 같음] + 1×[생활 같음] + 1×[에너지 다름]` (0~7) → 40 + s/7×45 + 정서 가산(둘 다 C 15 / 섞임 10 / 둘 다 E 5). 재미와 참고용 지수입니다.

## 왜 MBTI보다 정확하다고 설계했나
| MBTI의 약점 | 이 검사의 대응 |
|---|---|
| 이분법이라 경계선 사람의 유형이 바뀜 | 7점 척도, 0~100% 점수, 경계 표시와 인접 유형 안내 |
| 정서 안정성 축이 없음 | 5번째 축(-C/-E) 추가 |
| 묵종 편향 | 축마다 정방향·역방향 문항을 절반씩 |
| 결과가 글자 4개뿐 | 하위 측면 10개 세부 점수 |
| 성의 없는 응답도 그대로 반영 | 응답 신뢰도 검사와 경고 |

뼈대는 학계에서 검증이 많이 된 Big Five(5요인) 모델과 하위 측면 구조(DeYoung 등의 BFAS)입니다.

> **한계:** 위 내용은 설계상의 근거입니다. 이 검사의 문항은 새로 작성한 것으로, 아직 실제 응답 데이터로 신뢰도(크론바흐 α, 재검사 신뢰도)나 규준을 검증하지 않았습니다. 진단 도구가 아니며 자기 이해와 재미를 위한 용도입니다.
> 검증하려면 (1) 응답 수백 건 이상 수집, (2) 문항-측면 요인분석과 α 계산, (3) 2~4주 뒤 재검사 일치도 확인, (4) 문제 있는 문항 교체 순서로 진행하면 됩니다.

## 파일 구조
```
index.html        화면 (시작 · 검사 · 결과 · 유형 목록 · 궁합)
css/style.css     스타일 (모바일, 다크 모드, 인쇄)
js/questions.js   60문항
js/scoring.js     채점 · 신뢰도 · 궁합 (DOM 의존 없음)
js/content.js     축 · 하위 측면 · 기질 · 정서 · 궁합 문장
js/types*.js      16유형 상세 설명
js/app.js         화면 동작
tests/verify.js   채점과 콘텐츠 점검  →  node tests/verify.js
tests/serve.js    로컬 미리보기      →  node tests/serve.js
```

## 실행과 점검
```bash
# 그냥 index.html을 더블클릭해도 되고, 로컬 서버로 볼 수도 있습니다
node tests/serve.js     # http://localhost:5173
node tests/verify.js    # 모든 점검 통과 여부 확인
```

`main` 브랜치 루트를 GitHub Pages로 배포합니다. Settings → Pages에서 Branch를 `main` / `(root)`로 지정하면 됩니다.
