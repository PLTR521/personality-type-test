# 결 성격유형 테스트

10문항, 약 1분짜리 **재미로 보는** 성격유형 테스트입니다. 서버 없이 `index.html`만 열면 동작하고 외부 라이브러리도 없습니다.

배포 주소: https://pltr521.github.io/personality-type-test/

## 어떻게 동작하나
- 5개 축 × 2문항 = 10문항. 질문과 순서는 항상 같습니다(`js/questions.js`).
- 5점 척도(전혀 아니다 … 매우 그렇다)로 답하고, 고르면 바로 다음 문항으로 넘어갑니다.
- 결과는 4글자 유형(16가지) + 정서 접미사 `-C/-E`.

| 축 | A | B |
|---|---|---|
| 에너지 | O 외향 | R 내향 |
| 인식 | V 탐구 | G 현실 |
| 판단 | H 공감 | L 원칙 |
| 생활 | S 계획 | F 유연 |
| 정서 | C 안정 | E 민감 |

## 채점
축마다 두 문항의 점수를 합칩니다. 점수 = 응답(-2~+2) × 문항 방향(A 방향 +1, B 방향 -1). 합이 0보다 크면 A, 작으면 B입니다. 0점이면 그 축의 첫 문항이 기우는 쪽을 따르고, 그것도 0이면 B입니다.

## 결과 화면
유형 이름과 한 줄 소개, 5개 축 그래프, 특징, 강점·주의점, 어울리는 직업, 잘 맞는/서로 채워 주는/부딪히기 쉬운 유형, 한 줄 조언, 그리고 "더 자세히 보기"(연애·친구·일·스트레스 등). 결과 링크(`#r=` 뒤에 10자리 숫자)로 공유할 수 있습니다.

> 10문항짜리 가벼운 테스트라 정확한 검사가 아닙니다. 진단이나 전문 평가로 쓰지 마세요.

## 파일
```

js/questions.js   10문항
js/scoring.js     채점 · 궁합 계산
js/content.js     축 · 기질 · 정서 · 관계 문장
js/types*.js      16유형 설명
js/app.js         화면 동작
tests/verify.js   채점과 콘텐츠 점검  →  node tests/verify.js
tests/serve.js    로컬 미리보기      →  node tests/serve.js  (http://localhost:5173)
```
